# pleasegame

## LETHE // 기억 삭제 클리닉

브라우저에서 바로 실행되는 서사 중심 웹 게임입니다. `lethe.html` 파일 하나만 열면 처음부터 엔딩까지 플레이할 수 있습니다.

- 10일 · 3막 구성, 플레이 타임 약 2~3시간
- 손님 27회 등장, 저녁 사이드 퀘스트, 하린 다이브 3회, 엔딩 11개 (진엔딩은 2회차)
- 날짜별 자동 저장, 클리어 후 챕터 선택 · 엔딩 갤러리 · 녹음기 · 미오의 그림첩
- 기획서: `docs/LETHE_확장기획서.md`

### 소스 구조와 빌드

`lethe.html`은 `src/`의 파트 파일을 순서대로 합친 결과물입니다. 수정은 `src/`에서 하고 빌드하세요.

```bash
./build.sh   # src/*.html, src/*.js → lethe.html
```

| 파일 | 내용 |
|---|---|
| `src/00_head.html` ~ `03_body.html` | HTML 머리, 스타일, 본문 뼈대 |
| `src/10_config.js` | 설정, 10일 규칙, 내 기억 8개, 단서·음성 메시지, 스크립트 문법 |
| `src/12_chars.js` | 등장인물 도트 초상 설정 |
| `src/34_drawings.js` | 미오의 크레파스 그림 |
| `src/20_act1.js` · `21_act2.js` · `22_act3.js` | 막별 손님 · 아침 · 저녁 · 다이브 · 인터루드 |
| `src/23_endings.js` | 엔딩 11개와 에필로그 슬라이드 |
| `src/30_core.js` ~ `43_ending.js` | 엔진 (상태·저장, 도트, 대화, 화면) |
